# Cuttles Dog Grooming & Boutique

Mock marketing site for a fictional dog grooming studio and pet boutique, built with Next.js + Tailwind CSS. Design system (palette, type, spacing, motion, paw-print texture) shared with the OmniGrid Digital "warm sage & coral" pet-business template used across sibling projects.

This is a **mock/demo build**: business details, address, phone number, hours, reviews and photography are placeholder content. Swap `src/data/*.ts` with real business info and replace `/public/images/*.jpg` 1:1 with real photography before launch. The booking modal is a front-end mock only — it does not send email or persist anywhere; wire it to a real backend before going live.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- lucide-react icons

## Getting started

```bash
npm install
npm run generate-images   # regenerates placeholder photography
npm run dev
```
